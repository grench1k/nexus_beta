# Nexus

Анонимный мессенджер для геймеров. Серверы, каналы и голосовые комнаты — без телефона, почты и слежки.

## Принципы

- **No identity** — аккаунт = криптографический ключ (ed25519)
- **No metadata** — сервер не знает, кто ты
- **No lock-in** — ключ можно экспортировать

## Запуск локально

```bash
go mod tidy
go run main.go
